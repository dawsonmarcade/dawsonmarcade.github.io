## Monte Carlo Probability Simulator

This project demonstrates how Monte Carlo Simulations can be used to: 
-Estimate probabilities and expected values
-Validate analytical solutions
-Visualize convergence behavior
-Quantify uncertainty using bootstrap confidence intervals

### Key Concepts
- Law of Lage Numbers
- Sampling variability
- Convergence Rate O(1/sqrt(n))
- Tradeoff between computational cost and accuracy

### Use Cases
- Risk Modeling
- A/B testing validation
- Financial Simulations
